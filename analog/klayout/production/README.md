# Production openDVS pixel macro -- KLayout workspace

- `pixel_4tile_mag_9_1_pruned.gds` -- pristine production macro (read-only, sha256 209d312b...),
  identical to the PEX campaign's `production_pixel_macro` authority on rpgraca-ini.
- `pixel_4tile_work.gds` -- the editable copy. One file holds the whole hierarchy:
  `pixel_4tile` -> `pixel_layout_tile`/`_bot` -> `openDVS_pixel2x2_top`/`_bot` -> `openDVS_pixel`.
  Edit `openDVS_pixel` once and every 2x2 and the 4-tile view follow.
- `./open_production.sh` -- opens the working copy editable with the sky130 tech.
- Tools -> "openDVS: extract nets" (Ctrl+Shift+N) -- extracts the current cell in memory and opens the
  Netlist Browser; click a net to highlight it. Re-run after edits. Writes `<file>.<cell>.l2n` alongside.
- Batch: `klayout -b -r opendvs_l2n.py -rd gds=pixel_4tile_work.gds -rd top=openDVS_pixel2x2_top`
- `openDVS_pixel_4x4` (second top cell in the work file) -- 4x4-pixel window of `pixel_layout_tile`: the
  2x2 block of `openDVS_pixel2x2_top` *instances* at (col 15, row 10) of the 32x32 array plus copies of
  the tile-level shapes clipped to that block. Pixel / 2x2 edits propagate into it and into `pixel_4tile`;
  tile-level edits do not (copies). Regenerate with `klayout -b -r add_4x4.py` (never hand-edit that cell).
- `*.l2n` files are extraction outputs, regenerated by the macro -- disposable.
- LVS of the 2x2 vs `analog/xschem/openDVS_pixel2x2.sch`: `./run_lvs_2x2.sh` (exports the cell as top
  `openDVS_pixel2x2`, netlists the schematic with xschem `lvs_netlist`, runs the ciel sky130 deck with
  `convert_subckts=true lvs_sub=GndA`; env `RUN_MODE=deep|flat GDS=<other.gds> TAG=<suffix>`), then
  `klayout -b -r lvs_compare_flat.py -rd db=lvs/<cell><tag>.lvsdb` for the verdict. The deck alone cannot
  pass: abutting pixels share S/D diffusion, so deep mode pulls 16 devices/2x2 into the parent circuit
  and flat mode merges abutting gates into 4x-wide devices. The compare script flattens the pixel on
  both sides, ties the nwell net to VddA18 (taps are at tile level) and drops MIM caps (schematic has
  none). Pristine production 2x2: MATCH (80 devices, 61 nets). `lvs_diff.py` / `lvs_nets.py` /
  `lvs_report.py` dump device inventories, net signatures and the xref for debugging.
